Vice Cover Studio turns your photos into a Vice City-style multi-panel poster cover — pick a layout, grade and caption, crop each panel, and export a PNG to share. It runs fully offline in the browser and your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` to build the hand-in bundle in `out/`.
